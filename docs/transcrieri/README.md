# Transcrieri — seria Geneza a păstorului Allen Nolan

Aici stau transcrierile luate de pe YouTube, ca să fie cântărite. Nu sunt conţinut
al aplicaţiei şi nu se copiază din ele nicio frază — sunt materie de verificare.

Rezultatul cântăririi se scrie în `docs/26-cantarirea-transcrierilor.md`, pe trei
coşuri: **de luat**, **de verificat**, **de lăsat**.

## Cum se numesc fişierele

`nolan-<episoade>-geneza-<capitole>.md`

Pilde:

- `nolan-01-09-geneza-1-9.md`
- `nolan-10-14-geneza-3.md`
- `nolan-50-geneza-24.md`

Dacă nu se ştie la ce capitol e episodul, e de ajuns numărul episodului:
`nolan-27.md`.

## Ce se pune înăuntru

Textul aşa cum iese de pe YouTube. Nu trebuie curăţat: minutele, semnele de
îngroşare, cuvintele stricate de subtitrare — toate se citesc şi aşa.

Dacă într-un fişier intră mai multe episoade, se pune un titlu înaintea fiecăruia:

```
## Episodul 7 — Geneza 3:1-7
```

## Ce s-a cântărit până acum

- **Episodul 1** (întemeierea, fără text din Geneza) — cântărit. Acolo s-a aflat că
  seria la Geneza **nu este verset cu verset**, ci pe întâmplările de seamă şi pe
  oameni; el o spune la minutul 1:12.
