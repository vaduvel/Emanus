# Transcrieri

Aici stau transcrierile luate de pe YouTube, ca să fie cântărite. Nu sunt conţinut
al aplicaţiei şi nu se copiază din ele nicio frază — sunt materie de verificare.

Două serii stau aici:

- **Geneza** — păstorul Allen Nolan (`nolan-*`).
- **Matei** — Zac Poonen, *Verse By Verse Study* (`poonen-*`).

---

## Seria Geneza — Allen Nolan

Rezultatul cântăririi se scrie în `docs/26-cantarirea-transcrierilor.md`, pe trei
coşuri: **de luat**, **de verificat**, **de lăsat**.

### Cum se numesc fişierele

`nolan-<episoade>-geneza-<capitole>.md`

Pilde:

- `nolan-01-09-geneza-1-9.md`
- `nolan-10-14-geneza-3.md`
- `nolan-50-geneza-24.md`

Dacă nu se ştie la ce capitol e episodul, e de ajuns numărul episodului:
`nolan-27.md`.

### Ce s-a cântărit până acum

- **Episodul 1** (întemeierea, fără text din Geneza) — cântărit. Acolo s-a aflat că
  seria la Geneza **nu este verset cu verset**, ci pe întâmplările de seamă şi pe
  oameni; el o spune la minutul 1:12.

---

## Seria Matei — Zac Poonen

Izvorul: playlistul *Verse By Verse Study*, canalul `youtube.com/@ZacPoonenVerseByVerse`,
`PL3myepmxcTQTGm4DX3YBQoerq4Ee7AM6u`. Episodul 1 este *Matthew 1:1 to 1:10*.
Seria aceasta **este cu adevărat verset cu verset**, pe bucăţi de opt-zece versete.

Rezultatul cântăririi se scrie în `docs/34-cantarirea-poonen-matei.md`, pe aceleaşi
trei coşuri.

### Cum se numesc fişierele

`poonen-<episod>-matei-<capitol>-<versete>.md`

Pilde:

- `poonen-01-matei-1-1-10.md`
- `poonen-02-matei-1-11-25.md`
- `poonen-07-08-matei-5.md`

Numărul episodului se scrie cu două cifre, ca să stea în rând la listare.

### Ce se cere în capul fişierului

Trei rânduri, ca să se ştie de unde vine şi ce acoperă:

```
# Episodul 1 — Matei 1:1-10

- video: https://www.youtube.com/watch?v=2-5Oi2QmtgA
- titlu: 1. Matthew 1:1 to 1:10 - Zac Poonen - Verse By Verse Study
```

După acestea, textul brut.

### Un lucru de ţinut minte la cântărire

Poonen citeşte din *New American Standard Bible*. Toate temeiurile lui care stau pe
un cuvânt englezesc se rup în Cornilescu 1924 şi se prind la cântărire, nu la
scriere.

---

## Ce se pune înăuntru (amândouă seriile)

Textul aşa cum iese de pe YouTube. Nu trebuie curăţat: minutele, semnele de
îngroşare, cuvintele stricate de subtitrare — toate se citesc şi aşa.

Dacă într-un fişier intră mai multe episoade, se pune un titlu înaintea fiecăruia:

```
## Episodul 7 — Geneza 3:1-7
```
