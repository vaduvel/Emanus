## Ce inseamna, pentru noi, "fara alterari"

Trecerea in limba romana este traducere, nu alterare. Alterare ar fi modificarea
textului, a doctrinei, a invataturii sau a ideilor. Acestea se pastreaza.

Regula de lucru:

- **invatatura este a autorului** - ideile, argumentele, ilustratiile si concluziile
  se traduc fidel din textul lui, nu se rescriu si nu se rezuma pana isi pierd sensul;
- **de la noi vin doar schelele de navigare** - intrebarea de inceput, butoanele de
  alegere, promptul de jurnal, impartirea pe pasi. Zero doctrina adaugata;
- **versetele** se iau din traducerea romaneasca folosita in aplicatie, nu se traduc
  din engleza de catre noi;
- **nu punem in gura autorului** lucruri pe care nu le-a spus. Daca o tema nu a fost
  citita din sursa, nu se scrie modul pentru ea.

## Regula de verificare inainte de scriere

Niciun modul nu se scrie inainte de a citi textul sursa al temelor pe care le acopera.
Aceasta regula a fost incalcata o data, la prima versiune a modulului "De ce dam gres"
(temele 22-24 si 72), scrisa fara citirea capitolelor. Acel modul se rescrie din sursa.
