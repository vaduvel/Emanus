# Biblia explicată — valul Ioel

- Carte: **Ioel**
- Capitole: **3 / 3**
- Biblia Emanus: `JOL`
- Sursă Poonen: episod oficial CFC `Hosea, Joel`
- Stare: `in_review`

Teme oficiale: judecata prezentă; pocăința înaintea revărsării Duhului; Ziua DOMNULUI care vine.

Ebraică: `רוּחִי` (`ruhi`) — «Duhul Meu», Ioel 2:28, WLC-OSHB.

Protecții: dezastrele moderne nu sunt declarate automat judecăți divine; revărsarea Duhului nu validează automat orice profeție; imaginile Zilei DOMNULUI nu autorizează violență religioasă.
