# Biblia explicată — valul Hagai

- Carte: **Hagai**
- Capitole: **2 / 2**
- Biblia Emanus: `HAG`
- Sursă Poonen: episod oficial CFC `Zephaniah, Haggai`
- Stare: `in_review`

Secțiuni oficiale: terminați templul; templul va fi glorios; cei ascultători vor fi binecuvântați; Zorobabel va fi onorat.

Ebraică: `שִׂימוּ לְבַבְכֶם עַל־דַּרְכֵיכֶם` — «cercetați-vă căile», Hagai 1:5, WLC-OSHB.

Protecții: Hagai nu este formulă de prosperitate financiară pentru donații/clădiri; promisiunile lui Zorobabel nu sunt titluri generice pentru lideri moderni.
