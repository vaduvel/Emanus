# Biblia explicată — valul Iona

- Carte: **Iona**
- Capitole: **4 / 4**
- Biblia Emanus: `JON`
- Sursă Poonen: episod oficial CFC `Jonah, Micah`
- Stare: `in_review`

Tema distinctivă Poonen: iubirea lui Dumnezeu pentru toate națiunile. Structură: prima însărcinare; a doua însărcinare.

Ebraică: `רַב־חֶסֶד` (`rav-hesed`) la Iona 4:2, WLC-OSHB.

Protecții: cererea lui Iona de a fi aruncat în mare nu este model de auto-vătămare; mila pentru Ninive nu minimizează răul cetății; minunea peștelui este păstrată conform narațiunii fără speculație biologică.
