# Biblia explicată — valul Eclesiastul

- Carte: **Eclesiastul**
- Capitole structurale: **12 / 12**
- Biblia Emanus: `ECC`
- Transcript: `ecclesiastes.txt`
- Stare: `in_review`
- Mod: `transcript-focused`

Focare: «sub soare», limitele inteligenței, plăcere/muncă/realizări, timpul, cuvintele și jurămintele, sfaturile din cap. 7–9, concluzia din cap. 12.

Protecții: afirmațiile pesimiste nu sunt extrase ca doctrina completă a Scripturii; Eclesiastul 7:28 nu este folosit pentru misoginie; rațiunea nu este condamnată, ci limitată ca autoritate spirituală; concluzia fricii de judecată este citită alături de motivația iubirii din Noul Testament.

Ebraică: `הֲבֵל הֲבָלִים` (`havel havalim`) — imaginea aburului/deșertăciunii din 1:2, WLC-OSHB.
