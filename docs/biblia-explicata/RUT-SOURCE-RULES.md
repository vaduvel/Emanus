# Rut — reguli de sursă pentru Biblia explicată

Acest val pornește numai din ramura `agent/transcrieri-poonen-VT` și din cele patru capitole Biblia Emanus pentru Rut.

## Regula doctrinară

- Textul biblic este Biblia Emanus și rămâne separat de explicație.
- Explicația doctrinară și aplicația urmează transcrierea Poonen `judges-ruth.txt`.
- Reformularea este permisă numai pentru limba română, claritate și structură.
- Nu se adaugă din memoria modelului contexte, doctrine, tipologii, trimiteri sau aplicații pe care transcrierea nu le susține.
- Când o afirmație din transcriere pare greșită, deplasată sau produsă de Whisper, ea se verifică separat înainte de folosire.

## Cuvinte ebraice

Studiile lexicale sunt un strat separat de explicația Poonen.

Un termen ebraic intră numai dacă:

1. este important pentru sensul pasajului;
2. forma lui apare în textul WLC-OSHB folosit de Biblia Emanus;
3. lema, transliterarea și sensul contextual sunt verificate într-o sursă lexicală identificabilă;
4. nota nu introduce o doctrină nouă și nu folosește etimologia ca argument doctrinar;
5. sursa lexicală și referința biblică sunt păstrate pentru audit.

Dacă Poonen explică el însuși un termen din limba originală, se păstrează și ancora exactă din transcript. Dacă nu îl explică, nota lexicală este etichetată separat și nu este prezentată ca învățătura lui Poonen.
