# Biblia explicată — valul Habacuc

- Carte: **Habacuc**
- Capitole: **3 / 3**
- Biblia Emanus: `HAB`
- Sursă Poonen: episod oficial CFC `Nahum, Habakkuk`
- Stare: `in_review`

Tema distinctivă: conflictul și triumful credinței. Structură: prima întrebare; răspunsul lui Dumnezeu; a doua întrebare; răspunsul lui Dumnezeu; lauda lui Habacuc.

Ebraică: `אֱמוּנָתוֹ` (`emunato`) la Habacuc 2:4, WLC-OSHB.

Protecții: folosirea Babilonului nu îi declară violența bună; «cel drept va trăi prin credință» nu este formulă de prosperitate; lauda din cap. 3 nu neagă pierderea reală.
