# NT explicat — raport de recuperare curată

## Verdict intermediar

Catalogul legacy `agent/complete-new-testament` conține structural **27/27 cărți, 260/260 capitole**. Textul biblic vechi nu este importat. Fiecare interval este validat față de **Biblia Emanus BE publicată (7941 versete NT)**, iar numerele absente din textul critic sunt acceptate numai când BE le păstrează ca note critice rezolvate.

- **15 cărți / 191 capitole**: conținut editorial recuperat, obligatoriu de auditat source-first Poonen/CFC înainte de publicare.
- **12 cărți / 69 capitole**: completion generic; rămâne în carantină și trebuie reconstruit direct din sursa Poonen/CFC.
- **16 sloturi numerice critice** sunt păstrate ca referințe, nu transformate în versete BE.
- **Publicare: BLOCATĂ** până la auditul integral 27/27 și 260/260.

## Regula doctrinară

Unde Zac Poonen/CFC dezvoltă pasajul, explicația finală păstrează doctrina, interpretarea, tipologia și aplicația lui fără diluare sau relativizare. Numele sursei rămâne în provenance intern; reader-ul public nu îl expune. În golurile reale ale sursei se poate folosi numai rezumat textual sau exegeza canonică verificată, clar separată.
