# Biblia explicată — valul Obadia

- Carte: **Obadia**
- Capitole: **1 / 1**
- Biblia Emanus: `OBA`
- Sursă Poonen: episod oficial CFC `Amos, Obadiah`
- Stare: `in_review`

Tema distinctivă Poonen: mândria și rezultatele ei. Secțiuni: judecata Edomului; restaurarea Israelului.

Ebraică: `זְדוֹן` (`zedon`) — mândrie/aroganță, Obadia 1:3, WLC-OSHB.

Protecții: profeția despre Edom nu este folosită pentru ostilitate etnică modernă; judecata aparține lui Dumnezeu, nu răzbunării private.
