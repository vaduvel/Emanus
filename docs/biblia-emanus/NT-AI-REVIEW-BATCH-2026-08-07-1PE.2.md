## Decizii pe verset

| Referință BE | Ancoră SBLGNT verificată | Decizie de redactare |
| --- | --- | --- |
| 1PE.2.1 | `Ἀποθέμενοι … πᾶσαν κακίαν … πάσας καταλαλιάς` | Participiul inițial este păstrat prin „lepădând”, iar lista cuprinde răutatea, viclenia, fățărniciile, invidiile și toate vorbirile de rău. SBLGNT și TR au aici pluralul `ὑποκρίσεις`. |
| 1PE.2.2 | `τὸ λογικὸν ἄδολον γάλα … αὐξηθῆτε εἰς σωτηρίαν` | `λογικόν` și `ἄδολον` sunt redate „spiritual și curat”; SBLGNT păstrează destinația „spre mântuire”, omisă în TR. |
| 1PE.2.3 | `εἰ ἐγεύσασθε ὅτι χρηστὸς ὁ κύριος` | Condiționalul SBL `εἰ` devine „dacă”; TR citește condiționalul întărit `εἴπερ`, care nu este importat în text. `χρηστός` este redat „bun”. |
| 1PE.2.4 | `πρὸς ὃν προσερχόμενοι, λίθον ζῶντα` | „Venind la El” păstrează participiul, nu îl transformă într-o afirmație nouă; piatra este vie, respinsă de oameni, dar aleasă și prețioasă înaintea lui Dumnezeu. |
| 1PE.2.5 | `οἰκοδομεῖσθε οἶκος πνευματικὸς εἰς ἱεράτευμα ἅγιον` | Credincioșii sunt zidiți într-o casă spirituală „spre a alcătui o preoție sfântă”. SBLGNT include `εἰς`, omis în TR; articolul suplimentar din TR înainte de `θεῷ` nu modifică sensul românesc. |
| 1PE.2.6 | `περιέχει ἐν γραφῇ … λίθον ἀκρογωνιαῖον ἐκλεκτὸν ἔντιμον` | Citatul vorbește despre piatra unghiulară aleasă și prețioasă, iar cel care crede în ea nu va fi dat de rușine. TR adaugă articolul în `ἐν τῇ γραφῇ` și inversează două adjective, fără diferență de sens în română. |
| 1PE.2.7 | `ἀπιστοῦσιν δὲ` | SBLGNT are „cei care nu cred”, nu `ἀπειθοῦσιν` („cei neascultători”) din TR. Citatul despre piatra respinsă de zidari rămâne unit cu versetul următor. |
| 1PE.2.8 | `λίθος προσκόμματος καὶ πέτρα σκανδάλου … εἰς ὃ καὶ ἐτέθησαν` | „Piatră de poticnire și stâncă de cădere” păstrează imaginile distincte. „La aceasta au fost și rânduiți” redă pronumele deschis `εἰς ὃ` fără o glosă doctrinară adăugată. |
| 1PE.2.9 | `γένος ἐκλεκτόν … λαὸς εἰς περιποίησιν … τὰς ἀρετὰς` | `γένος` este „neam”, `βασίλειον ἱεράτευμα` este „preoție regală”, iar `λαὸς εἰς περιποίησιν` devine „un popor care Îi aparține”. `ἀρετάς` este redat „mărețiile”, nu redus la simple trăsături morale. |
| 1PE.2.10 | `οὐκ ἠλεημένοι … ἐλεηθέντες` | Forma pasivă este păstrată: celor cărora nu li se arătase îndurare li s-a arătat acum îndurare. Nu este introdus un agent suplimentar în afară de Dumnezeu deja numit. |
| 1PE.2.11 | `παροίκους καὶ παρεπιδήμους … σαρκικῶν ἐπιθυμιῶν` | Perechea este redată „străini și trecători”, iar poftele sunt numite „trupești”, cele care se războiesc împotriva sufletului. |
| 1PE.2.12 | `ἐποπτεύοντες δοξάσωσι` | SBLGNT are participiul prezent „văzând faptele voastre bune”; TR are aoristul `ἐποπτεύσαντες`. Textul păstrează defăimarea ca răufăcători și slăvirea lui Dumnezeu în ziua cercetării. |
| 1PE.2.13 | `Ὑποτάγητε πάσῃ ἀνθρωπίνῃ κτίσει διὰ τὸν κύριον` | `κτίσις` este redat „instituție omenească”, iar `διὰ τὸν κύριον` „de dragul Domnului”. TR adaugă `οὖν`; textul nu adaugă această legătură absentă din SBLGNT. |
| 1PE.2.14 | `εἰς ἐκδίκησιν … ἔπαινον` | Guvernatorii sunt trimiși pentru pedepsirea răufăcătorilor și lauda celor care fac binele; `ἐκδίκησις` nu este atenuat într-o vagă „corectare”. |
| 1PE.2.15 | `ἀγαθοποιοῦντας φιμοῦν … ἀγνωσίαν` | A face binele „reduce la tăcere” neștiința oamenilor nechibzuiți; verbul `φιμόω` nu este redus la simpla contrazicere. |
| 1PE.2.16 | `ἐπικάλυμμα … τῆς κακίας … θεοῦ δοῦλοι` | Libertatea nu este „acoperământ al răutății”; termenul `δοῦλοι` rămâne „robi ai lui Dumnezeu”. SBLGNT și TR diferă numai prin ordinea cuvintelor. |
| 1PE.2.17 | `πάντας τιμήσατε … τὴν ἀδελφότητα ἀγαπᾶτε` | Cele patru imperative sunt păstrate distinct. SBLGNT are prezentul `ἀγαπᾶτε`, în timp ce TR are aoristul `ἀγαπήσατε`; româna firească „iubiți frăția” nu nivelează celelalte imperative. |
| 1PE.2.18 | `Οἱ οἰκέται … τοῖς δεσπόταις … τοῖς σκολιοῖς` | `οἰκέται` devine „sclavilor din casă”, iar `δεσπόταις` „stăpânilor”; nu este eufemizat raportul social. Ultimul adjectiv este redat „nedrepți”, nu ca o etichetă psihologică modernă. |
| 1PE.2.19 | `τοῦτο γὰρ χάρις … διὰ συνείδησιν θεοῦ` | `χάρις` în acest context este redat „un lucru plăcut înaintea lui Dumnezeu”; motivul rămâne conștiința față de Dumnezeu și suferința nedreaptă. |
| 1PE.2.20 | `ποῖον … κλέος … κολαφιζόμενοι … τοῦτο χάρις παρὰ θεῷ` | Lipsa laudei pentru îndurarea loviturilor după păcat este contrastată cu suferința îndurată în timp ce faci binele. `κολαφιζόμενοι` este explicit „sunteți loviți cu pumnul”. |
| 1PE.2.21 | `ὑπὲρ ὑμῶν, ὑμῖν / ὑπὲρ ἡμῶν, ἡμῖν` | SBLGNT spune „pentru voi, lăsându-vă un exemplu”; TR spune „pentru noi, lăsându-ne”. Ambele pronume ale lecturii SBL sunt păstrate. |
| 1PE.2.22 | `ἁμαρτίαν οὐκ ἐποίησεν … δόλος` | Sunt păstrate absența păcatului și a vicleniei în gura lui, fără completări explicative la citatul din Isaia. |
| 1PE.2.23 | `λοιδορούμενος οὐκ ἀντελοιδόρει … παρεδίδου` | În timp ce era insultat nu răspundea cu insulte, iar în suferință nu amenința; imperfectele sunt redate prin acțiuni continue, culminând cu încredințarea în Cel care judecă drept. |
| 1PE.2.24 | `ἀπογενόμενοι … οὗ τῷ μώλωπι / οὗ τῷ μώλωπι αὐτοῦ` | Păcatele sunt purtate „în trupul Său, pe lemn”, pentru ca noi, murind față de păcate, să trăim pentru dreptate. SBLGNT nu repetă `αὐτοῦ` după `μώλωπι`; „prin rana Lui” păstrează antecedentul relativ `οὗ`. |
| 1PE.2.25 | `πλανώμενοι / πλανώμενα … ποιμένα καὶ ἐπίσκοπον` | SBLGNT are participiul masculin pentru destinatari, TR pe cel neutru acordat cu „oi”; „vă rătăceați ca niște oi” păstrează subiectul. `ἐπίσκοπον` este redat descriptiv „Supraveghetorul”, nu ca un titlu ecleziastic automat. |
