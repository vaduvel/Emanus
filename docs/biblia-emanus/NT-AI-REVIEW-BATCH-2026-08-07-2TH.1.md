## Decizii pe verset

| --- | --- | --- |
| 2TH.1.1 | `τῇ ἐκκλησίᾳ Θεσσαλονικέων ἐν θεῷ πατρὶ ἡμῶν καὶ κυρίῳ Ἰησοῦ Χριστῷ` | Expeditorii sunt Pavel, Silvan și Timotei; destinatara este „adunarea tesalonicenilor”, definită prin relația ei cu Dumnezeu Tatăl nostru și Domnul Isus Hristos. Sunt păstrate ambele prepoziții `ἐν`. |
| 2TH.1.2 | `ἀπὸ θεοῦ πατρὸς καὶ κυρίου Ἰησοῦ Χριστοῦ`; SBL/TR `πατρός / πατρὸς ἡμῶν` | Salutul spune „de la Dumnezeu Tatăl și de la Domnul Isus Hristos”. SBLGNT nu are `ἡμῶν` după „Tatăl”, astfel încât „nostru” din TR nu este importat. |
| 2TH.1.3 | `Εὐχαριστεῖν ὀφείλομεν … ὑπεραυξάνει … πλεονάζει` | Obligația de a mulțumi este redată „Suntem datori”; credința „crește peste măsură”, iar dragostea fiecăruia față de ceilalți „sporește”. Sunt păstrate atât intensificarea credinței, cât și caracterul reciproc al dragostei. |
| 2TH.1.4 | SBL/TR `αὐτοὺς ἡμᾶς / ἡμᾶς αὐτούς`; `ἐγκαυχᾶσθαι / καυχᾶσθαι` | „Noi înșine ne lăudăm cu voi” păstrează accentul SBLGNT. Perseverența, credința, persecuțiile și necazurile rămân distincte; variațiile TR nu sunt nivelate ca text principal. |
| 2TH.1.5 | `ἔνδειγμα τῆς δικαίας κρίσεως … καταξιωθῆναι … βασιλείας` | Suferințele sunt numite „o dovadă a judecății drepte”, iar `καταξιωθῆναι` devine „să fiți socotiți vrednici”. „Împărăția” redă `βασιλεία`, nu un calc administrativ precum „regat”. |
| 2TH.1.6 | `δίκαιον παρὰ θεῷ ἀνταποδοῦναι … θλῖψιν` | Dumnezeu este subiectul implicit al răsplătirii: „este drept ca Dumnezeu să-i răsplătească cu necaz”. Relația reciprocă dintre `θλίβουσιν` și `θλῖψιν` este păstrată prin „vă necăjesc / cu necaz”. |
| 2TH.1.7 | `τοῖς θλιβομένοις ἄνεσιν μεθʼ ἡμῶν … ἀποκαλύψει … ἀγγέλων δυνάμεως` | Celor necăjiți li se promite „ușurare împreună cu noi”. `ἀποκάλυψις` este redat prin descoperirea Domnului din cer, iar genitivul `ἀγγέλων δυνάμεως` rămâne „îngerii puterii Sale”. |
| 2TH.1.8 | SBL/TR `φλογὶ πυρός / πυρὶ φλογός`; `Ἰησοῦ / Ἰησοῦ Χριστοῦ` | SBLGNT dă „în flacără de foc” și numește „Evanghelia Domnului nostru Isus”. Sunt păstrate cele două grupe — cei care nu-L cunosc pe Dumnezeu și cei care nu ascultă de Evanghelie — fără adaosul `Hristos` din TR după prima ocurență a numelui. |
| 2TH.1.9 | `δίκην τίσουσιν ὄλεθρον αἰώνιον` | Pluralul `τίσουσιν` este redat corect: „Aceștia vor plăti pedeapsa”. `ὄλεθρον αἰώνιον` devine „nimicire veșnică”, fără a explica în plus natura pedepsei. |
| 2TH.1.10 | SBL/TR `πιστεύσασιν / πιστεύουσιν`; `ἐνδοξασθῆναι … θαυμασθῆναι` | Venirea în acea zi, glorificarea în sfinți și uimirea celor credincioși sunt păstrate. Aoristul SBLGNT `πιστεύσασιν` devine „cei care au crezut”, nu prezentul TR „cei care cred”. |
| 2TH.1.11 | `πᾶσαν εὐδοκίαν ἀγαθωσύνης καὶ ἔργον πίστεως ἐν δυνάμει` | Rugăciunea cere ca Dumnezeu să-i socotească vrednici de chemare și să împlinească „orice hotărâre bună și lucrare a credinței” cu putere. `εὐδοκία` nu este redusă la o emoție religioasă. |
| 2TH.1.12 | SBL/TR `Ἰησοῦ / Ἰησοῦ Χριστοῦ` la prima ocurență | Prima formulă rămâne „Numele Domnului nostru Isus”, iar formula finală este „Domnului Isus Hristos”, exact ca în SBLGNT. Versetul repară și dublarea coruptă „voi voi”. |
