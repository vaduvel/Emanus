## Decizii pe verset

| Referință BE | Ancoră SBLGNT verificată | Decizie de redactare |
| --- | --- | --- |
| 2TH.2.1 | `Ἐρωτῶμεν … ἐπισυναγωγῆς ἐπʼ αὐτόν` | Verbul inițial este „Vă rugăm însă”, iar `ἐπισυναγωγή` devine „adunarea noastră la El”; prepoziția păstrează direcția spre Hristos. |
| 2TH.2.2 | `μὴ ταχέως σαλευθῆναι … ἡ ἡμέρα τοῦ κυρίου` | Sunt păstrate clătinarea minții și tulburarea distinctă. SBLGNT spune „ziua Domnului”, nu „ziua lui Hristos” din TR. |
| 2TH.2.3 | `ἡ ἀποστασία … ὁ ἄνθρωπος τῆς ἀνομίας` | „Apostazia” trebuie să vină întâi, iar omul este al `ἀνομία`, „nelegiuire”, nu al `ἁμαρτία`, „păcat”, din TR. Elipsa despre ziua venită este completată prin antecedentul imediat, fără conținut escatologic suplimentar. |
| 2TH.2.4 | `ὁ ἀντικείμενος … ἀποδεικνύντα ἑαυτὸν ὅτι ἔστιν θεός` | Persoana se împotrivește, se înalță peste orice obiect de închinare, se așază în templu și se prezintă pe sine ca Dumnezeu. SBLGNT nu are adaosul TR `ὡς θεόν` după actul așezării. |
| 2TH.2.5 | `οὐ μνημονεύετε … πρὸς ὑμᾶς … ὑμῖν` | Toate adresările sunt la plural: Pavel se referă la comunitatea din Tesalonic, nu la o persoană singulară. |
| 2TH.2.6 | `τὸ κατέχον … ἀποκαλυφθῆναι αὐτὸν … καιρῷ` | Neutrul neidentificat este redat „ce îl reține”; omul nelegiuirii poate fi descoperit „la timpul lui”, nu „la sfârșit”. |
| 2TH.2.7 | `τὸ μυστήριον … ὁ κατέχων … ἐκ μέσου γένηται` | Taina nelegiuirii este deja activă. Elipsa despre reținător este redată fără a-i stabili identitatea, iar „cel care reține” este subiectul îndepărtat din mijloc. |
| 2TH.2.8 | `ὁ κύριος Ἰησοῦς ἀνελεῖ … καταργήσει` | SBLGNT îl numește pe „Domnul Isus” și are `ἀνελεῖ`, „va ucide / nimici”; TR omite numele și are alt verb. Ambele acțiuni viitoare sunt păstrate. |
| 2TH.2.9 | `παρουσία κατʼ ἐνέργειαν τοῦ Σατανᾶ … τέρασιν ψεύδους` | Venirea celui fără de lege se face potrivit lucrării Satanei, cu putere, semne și minuni mincinoase. |
| 2TH.2.10 | `ἐν πάσῃ ἀπάτῃ ἀδικίας τοῖς ἀπολλυμένοις` | Formula este redată „cu tot felul de amăgiri ale nedreptății pentru cei care se pierd”; motivul rămâne refuzul dragostei adevărului. |
| 2TH.2.11 | `πέμπει … ἐνέργειαν πλάνης … τῷ ψεύδει` | SBLGNT are prezentul „Dumnezeu le trimite”, nu viitorul TR. `ἐνέργεια πλάνης` este „o lucrare de rătăcire”, iar substantivul definit este „minciuna”. |
| 2TH.2.12 | `ἵνα κριθῶσιν πάντες … εὐδοκήσαντες τῇ ἀδικίᾳ` | Judecata îi privește pe toți cei care n-au crezut adevărul și și-au găsit plăcerea în nedreptate; nu este introdus termenul doctrinar „damnare”. |
| 2TH.2.13 | `εἵλατο … ἀπαρχὴν εἰς σωτηρίαν` | Diferență materială: SBLGNT are `ἀπαρχή`, „prim rod / pârgă”, iar TR `ἀπʼ ἀρχῆς`, „de la început”. Textul redă „v-a ales ca prim rod pentru mântuire”. |
| 2TH.2.14 | `εἰς ὃ ἐκάλεσεν … εἰς περιποίησιν δόξης` | „Pentru aceasta v-a chemat” păstrează antecedentul mântuirii; scopul este dobândirea slavei Domnului Isus Hristos. |
| 2TH.2.15 | `στήκετε … κρατεῖτε τὰς παραδόσεις` | Imperativele sunt „rămâneți neclintiți” și „țineți cu fermitate”. `παραδόσεις` rămâne „tradițiile”, adică învățăturile transmise oral și prin scrisoare, fără transfer instituțional modern. |
| 2TH.2.16 | `αὐτὸς δὲ … θεὸς ὁ πατὴρ ἡμῶν` | Începe o rugăciune care se încheie la versetul 17. SBLGNT are apoziția „Dumnezeu, Tatăl nostru”, nu coordonarea TR „Dumnezeu și Tatăl nostru”. |
| 2TH.2.17 | `παρακαλέσαι … στηρίξαι ἐν παντὶ ἔργῳ καὶ λόγῳ ἀγαθῷ` | Optativul de dorință/rugăciune devine „să vă mângâie … și să vă întărească”. SBLGNT nu repetă `ὑμᾶς` și păstrează ordinea „lucrare și cuvânt”, spre deosebire de TR. |
