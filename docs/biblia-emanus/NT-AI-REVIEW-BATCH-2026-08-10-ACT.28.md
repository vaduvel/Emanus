## Variante și decizii editoriale materiale

- **28:2** — `βάρβαροι` este redat contextual „localnicii”; termenul grec desemnează aici locuitorii non-greci, fără a cere conotația peiorativă modernă „barbari”.
- **28:4** — `ἡ δίκη` este păstrat ca „Dreptatea”, o personificare în vorbirea localnicilor; corpul nu adaugă numele unei zeițe sau o interpretare creștină.
- **28:11** — `Διοσκούροις` este redat „Dioscurii”; identificarea mitologică nu este introdusă în corp.
- **28:13** — SBLGNT selectează `περιελόντες`; în context nautic este redat „ridicând ancora”, nu prin lectura de tip „făcând un ocol”.
- **28:16** — textul principal SBLGNT are numai permisiunea dată lui Pavel de a locui separat cu soldatul care îl păzea. Extensia tradițională despre centurion și comandantul gărzii nu este introdusă.
- **28:22** — `αἵρεσις` este redat „grupare”, nu automat „sectă”.
- **28:25** — SBLGNT are `πρὸς τοὺς πατέρας ὑμῶν`, „către părinții voștri”; lectura tradițională cu persoana întâi nu este introdusă.
- **28:28** — SBLGNT include `τοῦτο`: „această mântuire a lui Dumnezeu”. Demonstrativul este păstrat.
- **28:29** — absent din textul principal SBLGNT. Lectura tradițională rămâne exclusiv în `referenceNotes`, între 28:28 și 28:30.
- **28:30** — SBLGNT are `Ἐνέμεινεν` cu subiect implicit; corpul nu importă numele „Pavel” explicit din lectura tradițională.
