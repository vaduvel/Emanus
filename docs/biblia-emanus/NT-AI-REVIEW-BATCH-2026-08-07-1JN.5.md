| 1JN.5.2 | `ὅταν … τὰς ἐντολὰς αὐτοῦ ποιῶμεν` | SBLGNT are `ποιῶμεν`; poruncile sunt „împlinite”, nu este importat automat `τηρῶμεν` („păzite”) din TR. |
| 1JN.5.3 | `ἡ ἀγάπη τοῦ θεοῦ … τηρῶμεν … βαρεῖαι` | Dragostea față de Dumnezeu este legată de păzirea poruncilor, care sunt redate „nu sunt apăsătoare”. |
| 1JN.5.4 | `πᾶν τὸ γεγεννημένον … ἡ πίστις ἡμῶν` | Este păstrat „tot ce s-a născut din Dumnezeu” și „credința noastră”; pronumele `ἡμῶν` nu este schimbat în „voastră”. |
| 1JN.5.5 | `τίς δέ ἐστιν ὁ νικῶν τὸν κόσμον` | Întrebarea retorică îl identifică pe biruitorul lumii drept cel care crede că Isus este Fiul lui Dumnezeu. |
| 1JN.5.6 | `διʼ ὕδατος καὶ αἵματος … οὐκ ἐν τῷ ὕδατι μόνον … τὸ πνεῦμά ἐστιν ἡ ἀλήθεια` | Este păstrată venirea prin apă și sânge, apoi contrastul „nu numai cu apă, ci cu apă și cu sânge”; Duhul mărturisește deoarece este adevărul. |
| 1JN.5.7 | `τρεῖς εἰσιν οἱ μαρτυροῦντες` | Textul are numai cei trei care mărturisesc. Comma Johanneum din TR nu este introdus în corpul principal. |
| 1JN.5.8 | `τὸ πνεῦμα καὶ τὸ ὕδωρ καὶ τὸ αἷμα … εἰς τὸ ἕν` | Martorii sunt Duhul, apa și sângele; expresia finală este redată prin acordul lor, nu printr-o afirmație trinitară adăugată. |
| 1JN.5.9 | `ὅτι αὕτη … ὅτι μεμαρτύρηκεν` | Cele două conjuncții `ὅτι` sunt păstrate ca explicație: aceasta este mărturia lui Dumnezeu, că El a mărturisit despre Fiul Său. Nu este importat pronumele relativ `ἥν` din TR. |
| 1JN.5.10 | `ἐν αὑτῷ … ψεύστην πεποίηκεν αὐτόν` | Credinciosul are mărturia în el însuși. Necredinciosul Îl face pe Dumnezeu mincinos prin neîncrederea în mărturia despre Fiul Său; inversarea de sens a textului anterior este eliminată. |
| 1JN.5.11 | `ζωὴν αἰώνιον ἔδωκεν ὁ θεὸς ἡμῖν` | Mărturia declară darul vieții veșnice și localizarea acestei vieți în Fiul lui Dumnezeu. |
| 1JN.5.12 | `ὁ ἔχων τὸν υἱὸν ἔχει τὴν ζωήν` | Contrastul dintre a-L avea pe Fiul și a nu-L avea este păstrat fără explicație doctrinară suplimentară. |
| 1JN.5.13 | `ὑμῖν ἵνα εἰδῆτε … τοῖς πιστεύουσιν` | Destinatarii care cred sunt așezați în apoziție la „voi”, iar unicul scop este să știe că au viață veșnică. Adaosul TR „și ca să credeți” nu este introdus. |
| 1JN.5.14 | `ἡ παρρησία … κατὰ τὸ θέλημα αὐτοῦ ἀκούει ἡμῶν` | Îndrăzneala înaintea lui Dumnezeu este legată de cererea făcută potrivit voii Lui și de faptul că El ne ascultă. |
| 1JN.5.15 | `τὰ αἰτήματα ἃ ᾐτήκαμεν ἀπʼ αὐτοῦ` | Sunt păstrate cererile făcute lui Dumnezeu și siguranța că ele sunt primite, fără a converti „a avea” într-o promisiune suplimentară. |
| 1JN.5.16 | `αἰτήσει … δώσει αὐτῷ ζωήν … ἁμαρτία πρὸς θάνατον` | Verbul este redat „va cere”; Dumnezeu este explicitat în română ca referent contextual al celui care dă viață. Textul nu definește confesional păcatul care duce la moarte. |
| 1JN.5.17 | `πᾶσα ἀδικία ἁμαρτία ἐστίν` | Orice nedreptate este păcat, iar versetul păstrează existența păcatului care nu duce la moarte. |

## Concluzie de lot

Textul anterior conținea, între altele, pronumele greșit „credința voastră” în
5:4, o inversare gravă de sens în 5:10, un al doilea scop introdus în 5:13,
formulări defectuoase în 5:16 și lectura reflexivă neacceptată de SBLGNT în
5:18. Comma Johanneum a fost eliminat din corpul versetelor 7–8 și consemnat
explicit ca variantă a martorului TR.
