## Decizii pe verset

| Referință BE | Ancoră SBLGNT verificată | Decizie de redactare |
| --- | --- | --- |
| 2JN.1.1 | `Ὁ πρεσβύτερος … ἐγνωκότες τὴν ἀλήθειαν` | Titlul epistolar „Bătrânul” este păstrat; adresarea cuprinde atât doamna aleasă, cât și copiii ei, iar „toți cei care cunosc adevărul” rămâne parte din aceeași frază. |
| 2JN.1.2 | `διὰ τὴν ἀλήθειαν … μεθʼ ἡμῶν ἔσται` | Versetul continuă motivul iubirii: adevărul rămâne în noi și va fi cu noi pentru totdeauna; au fost reparate substantivul lipsă și legătura sintactică. |
| 2JN.1.3 | `παρὰ Ἰησοῦ Χριστοῦ` | Salutul spune „de la Isus Hristos”, fără „Domnul”, deoarece SBLGNT nu are `κυρίου`, deși acesta apare în TR. |
| 2JN.1.4 | `τῶν τέκνων σου … ἐλάβομεν` | Destinatara este la singular („copiii tăi”), în timp ce autorul include comunitatea în „am primit poruncă”; ambele persoane sunt menținute. |
| 2JN.1.5 | `ἐρωτῶ σε, κυρία … ἵνα ἀγαπῶμεν ἀλλήλους` | Cererea este păstrată ca apel direct către doamnă, nu ca relatare a unei porunci deja trimise; porunca veche este iubirea reciprocă. |
| 2JN.1.6 | `περιπατῶμεν … ἠκούσατε … περιπατῆτε` | Prima formulare este la persoana întâi plural („să umblăm”), iar finalul se adresează plural destinatarilor („ați auzit”, „să umblați”); schimbarea nu este nivelată. |
| 2JN.1.7 | `ἐξῆλθον … Ἰησοῦν Χριστὸν ἐρχόμενον ἐν σαρκί` | SBLGNT are „au ieșit în lume”, nu lectura TR „au intrat”. Participiul despre Hristos este redat natural prin „venirea în trup a lui Isus Hristos”, fără a schimba lecturile grecești. |
| 2JN.1.8 | `ἀπολέσητε … ἀπολάβητε` | Avertismentul se adresează destinatarilor: „să nu pierdeți … să primiți”; nu urmează persoana întâi plural din TR. |
| 2JN.1.9 | `προάγων … μένων`; `τῇ διδαχῇ` | `προάγων` este redat „merge mai departe”, nu „încalcă”; în a doua propoziție, SBLGNT nu repetă „lui Hristos”, iar româna păstrează „în învățătură”. |
| 2JN.1.10 | `μὴ λαμβάνετε … χαίρειν αὐτῷ μὴ λέγετε` | Interdicția are destinatari la plural. „Nu-l primiți în casă și nici nu-l salutați” redă ospitalitatea și salutul fără repetiția coruptă a verbului. |
| 2JN.1.11 | `ὁ λέγων … χαίρειν κοινωνεῖ` | Persoana care îl salută se face părtaș la faptele lui rele; s-a restaurat propoziția completă și relația cu versetul precedent. |
| 2JN.1.12 | `γενέσθαι πρὸς ὑμᾶς … ἡ χαρὰ ὑμῶν` | Speranța de a ajunge la destinatari și de a vorbi față în față este păstrată. SBLGNT are „bucuria voastră”, nu „bucuria noastră” din TR. |
| 2JN.1.13 | `τῆς ἀδελφῆς σου τῆς ἐκλεκτῆς` | Salutul copiilor surorii alese este păstrat; „Amin” nu este adăugat, deoarece lipsește din lectura SBLGNT. |
