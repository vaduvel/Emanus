| 1TI.6.1 | `ὑπὸ ζυγὸν δοῦλοι … ἡ διδασκαλία βλασφημῆται` | Sunt păstrați „robii sub jug”, cinstea datorată stăpânilor și scopul ca numele lui Dumnezeu și învățătura să nu fie hulite. Nu este introdus un comentariu etic în corpul versetului. |

| 1TI.6.3 | `ἑτεροδιδασκαλεῖ … ὑγιαίνουσι λόγοις` | Este redată învățătura diferită, refuzul cuvintelor sănătoase ale Domnului Isus Hristos și învățătura potrivită cu evlavia. |
| 1TI.6.4 | `τετύφωται … νοσῶν περὶ ζητήσεις καὶ λογομαχίας` | „Este îngâmfat” și preocuparea bolnăvicioasă pentru controverse și certuri de cuvinte redau atât starea, cât și lista de consecințe care continuă în v. 5. |
| 1TI.6.5 | `διαπαρατριβαὶ … πορισμὸν εἶναι τὴν εὐσέβειαν` | Sunt redate certurile fără sfârșit ale oamenilor corupți în minte și ideea greșită că evlavia este mijloc de câștig. SBLGNT nu include imperativul final adăugat în TR. |
| 1TI.6.6 | `πορισμὸς μέγας … μετὰ αὐταρκείας` | `αὐτάρκεια` este redată prin „mulțumire”; afirmația spune că evlavia cu această mulțumire este un mare câștig, nu că evlavia însăși urmărește câștigul. |
| 1TI.6.7 | `οὐδὲν … ὅτι οὐδὲ ἐξενεγκεῖν τι δυνάμεθα` | Sunt păstrate nimicul adus în lume și imposibilitatea de a lua ceva din ea. Formula suplimentară TR „este limpede că” nu este introdusă. |
| 1TI.6.8 | `διατροφὰς καὶ σκεπάσματα` | Perechea este redată „hrană și îmbrăcăminte”, urmată de mulțumirea cu acestea. |
| 1TI.6.9 | `βουλόμενοι πλουτεῖν … βυθίζουσι` | Îndemnul privește pe cei care vor să se îmbogățească; ispitele, cursa și poftele îi afundă pe oameni în ruină și pieire. |
| 1TI.6.10 | `ῥίζα … πάντων τῶν κακῶν … ὀρεγόμενοι` | Iubirea de bani este „o rădăcină”, nu singura rădăcină, a relelor; unii care o doresc cu ardoare se rătăcesc de la credință și se străpung cu dureri. |
| 1TI.6.11 | `πραϋπαθίαν` | SBLGNT are termenul rar `πραϋπαθία`, redat „blândețea”; aparatul consemnează termenul înrudit `πρᾳότητα` din TR. Nu este atașată o distincție doctrinară artificială. |
| 1TI.6.12 | `ἀγωνίζου … ἐπιλαβοῦ τῆς αἰωνίου ζωῆς` | Două imperative personale sunt păstrate: lupta credinței și apucarea vieții veșnice, urmate de mărturisirea făcută înaintea multor martori. |
| 1TI.6.13 | `ζῳογονοῦντος τὰ πάντα … Χριστοῦ Ἰησοῦ` | Dumnezeu este „Cel care ține în viață toate lucrurile”, redând lectura SBLGNT `ζῳογονέω`, nu lectura TR `ζωοποιέω`. Ordinea numelui rămâne „Hristos Isus”. |
| 1TI.6.14 | `τηρῆσαί σε τὴν ἐντολὴν ἄσπιλον ἀνεπίλημπτον` | Porunca este păzită fără pată și fără vină până la arătarea Domnului Isus Hristos; nu se mută adjectivele într-o calitate diferită introdusă pentru Timotei. |
| 1TI.6.15 | `ἣν … δείξει ὁ μακάριος καὶ μόνος δυνάστης` | Pronumele se referă la arătarea din v. 14. „Cel binecuvântat și singurul Stăpânitor” o va arăta la timpul potrivit; identitatea nu este explicată confesional în text. |
| 1TI.6.16 | `φῶς οἰκῶν ἀπρόσιτον … κράτος αἰώνιον` | Este păstrată lumina inaccesibilă, imposibilitatea vederii de către oameni și doxologia cu cinste și putere veșnică. |
| 1TI.6.17 | `ἐπὶ θεῷ τῷ παρέχοντι` | Speranța se pune în Dumnezeu, care dă din belșug toate pentru bucurie. SBLGNT nu are adaosul TR „cel viu”. |
| 1TI.6.18 | `εὐμεταδότους … κοινωνικούς` | Cele două calități sunt păstrate distinct în română prin „darnici” și „gata să împartă”, după îndemnul de a face binele și de a fi bogați în fapte bune. |
| 1TI.6.19 | `τῆς ὄντως ζωῆς` | SBLGNT spune „viața adevărată”; nu este importată lectura TR „viața veșnică”. Păstrează totodată metafora strângerii unei temelii ca o comoară pentru viitor. |
| 1TI.6.20 | `τὴν παραθήκην φύλαξον … ψευδωνύμου γνώσεως` | Timotei păzește ceea ce i-a fost încredințat și evită vorbirile profane, deșarte și contradicțiile așa-zisei „cunoașteri”, fără identificarea ei cu un sistem ulterior. |
| 1TI.6.21 | `μεθʼ ὑμῶν` | Finalul are adresare la plural: „Harul să fie cu voi.” SBLGNT nu include singularul și „Amin” din TR. |
