## Decizii pe verset

| 1PE.5.1 | `Πρεσβυτέρους οὖν … συμπρεσβύτερος … κοινωνός` | `οὖν` este redat prin „Așadar”; autorul se numește el însuși bătrân, martor al suferințelor lui Hristos și părtaș la slava viitoare. |
| 1PE.5.2 | `ποιμάνατε … ἐπισκοποῦντες … κατὰ θεόν … προθύμως` | Sunt păstrate păstorirea, vegherea asupra turmei, libertatea motivului, expresia „după voia lui Dumnezeu” și râvna, fără câștig rușinos. |
| 1PE.5.3 | `μὴ … κατακυριεύοντες τῶν κλήρων … τύποι` | `κλήρων` este redat prin cei încredințați lor; conducerea dominatoare este opusă exemplului pentru turmă. |
| 1PE.5.4 | `φανερωθέντος τοῦ ἀρχιποίμενος … ἀμαράντινον` | Se păstrează pluralul destinatarilor, Păstorul cel mare și cununa slavei care nu se veștejește. |
| 1PE.5.5 | `ἀλλήλοις τὴν ταπεινοφροσύνην ἐγκομβώσασθε` | SBLGNT cere îmbrăcarea cu smerenie unul față de altul; adaosul TR despre supunerea reciprocă nu este introdus. |
| 1PE.5.6 | `Ταπεινώθητε … ἐν καιρῷ` | Îndemnul păstrează mâna puternică a lui Dumnezeu și înălțarea la vremea potrivită. |
| 1PE.5.7 | `πᾶσαν τὴν μέριμναν … αὐτῷ μέλει περὶ ὑμῶν` | Participiul este legat firesc de versetul 6: toate îngrijorările sunt aruncate asupra lui Dumnezeu, care se îngrijește de destinatari. |

| 1PE.5.9 | `ἀντίστητε στερεοὶ τῇ πίστει … ἀδελφότητι` | Rezistența este fermă în credință; suferințele sunt împărtășite de frații din lume. |
