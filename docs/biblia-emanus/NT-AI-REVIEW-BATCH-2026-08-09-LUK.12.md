## Variante și decizii editoriale materiale

- **12:5** — `ἐξουσία` este păstrat ca „autoritate”, fără a inventa în corp un nume pentru referentul pronumelui.
- **12:20** — pluralul impersonal `ἀπαιτοῦσιν` rămâne fără agent inventat: „ți se cere sufletul”.
- **12:25** — `ἡλικία` poate însemna statură sau vârstă/durată a vieții; combinația cu `πῆχυς` a fost redată „un cot la statura sa”, cu alternativa documentată.
- **12:31** — SBLGNT are `τὴν βασιλείαν αὐτοῦ`; nu se importă RP `τοῦ θεοῦ`, nici „mai întâi”, nici `πάντα` în propoziția următoare.
- **12:39** — SBLGNT urmează lectura scurtă `οὐκ ἂν ἀφῆκεν...`; WH/Treg/RP au lectura mai lungă cu `ἐγρηγόρησεν` („ar fi vegheat”).
- **12:42** — `οἰκονόμος` este administrator, iar `σιτομέτριον` porția/rația de hrană; vechiul „sfetnic” nu este fidel grecii.
- **12:46** — `διχοτομήσει` este păstrat lexical ca „îl va tăia în două”, fără eufemizare.
- **12:49** — expresia dificilă `τί θέλω εἰ ἤδη ἀνήφθη;` este redată ca dorință intensă ca focul să fie deja aprins, fără explicarea metaforei.
- **12:50** — `βάπτισμα ... βαπτισθῆναι` păstrează metafora botezului, iar `συνέχομαι` este redat prin apăsare/constrângere.
- **12:59** — `λεπτόν` este redat funcțional prin „bănuț”; alternativa tehnică „lepton” rămâne documentată.
