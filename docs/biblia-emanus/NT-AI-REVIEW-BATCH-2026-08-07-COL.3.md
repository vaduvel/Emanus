## Decizii pe verset

| COL.3.1 | `συνηγέρθητε τῷ Χριστῷ … ἐν δεξιᾷ τοῦ θεοῦ καθήμενος` | Aoristul pasiv este redat „ați fost înviați împreună cu Hristos”; sunt păstrate lucrurile de sus și Hristos așezat la dreapta lui Dumnezeu. |
| COL.3.2 | `τὰ ἄνω φρονεῖτε` | Imperativul este plural: „Gândiți-vă la lucrurile de sus”, nu forma singulară coruptă din redactarea anterioară. |
| COL.3.3 | `ἀπεθάνετε … ἡ ζωὴ ὑμῶν κέκρυπται` | Moartea destinatarilor și viața lor ascunsă cu Hristos în Dumnezeu sunt păstrate în aceeași propoziție. |
| COL.3.4 | `ἡ ζωὴ ὑμῶν` | Hristos este „viața voastră”; TR are „viața noastră”. Viitorul pasiv este redat prin arătarea lui Hristos și arătarea credincioșilor cu El în slavă. |
| COL.3.5 | `τὰ μέλη τὰ ἐπὶ τῆς γῆς … πλεονεξίαν` | Este păstrată metafora mădularelor care țin de pământ și lista: imoralitate sexuală, necurăție, patimă, dorință rea, lăcomie. SBL nu introduce posesivul explicit al TR. |
| COL.3.6 | `ἐπὶ τοὺς υἱοὺς τῆς ἀπειθείας` | Corpul SBLGNT arhivat include expresia cu delimitare tipografică; ea este păstrată „peste fiii neascultării”. Aparatul consemnează omiterea în WH/Treg, în timp ce TR o păstrează. |
| COL.3.7 | `ἐν οἷς … ἐν τούτοις` | Cele două referințe la lista anterioară sunt redate prin „în acestea” și „în ele”, fără a pierde timpul „odinioară”. |
| COL.3.8 | `ὀργήν, θυμόν, κακίαν, βλασφημίαν, αἰσχρολογίαν` | Sunt distincte mânia, furia, răutatea, defăimarea și vorbirea rușinoasă; sunt corectate repetarea greșită și trecerea nejustificată la singular. |
| COL.3.9 | `μὴ ψεύδεσθε εἰς ἀλλήλους … ἀπεκδυσάμενοι` | Interdicția minciunii rămâne la plural, urmată de dezbrăcarea omului vechi cu faptele lui. |
| COL.3.10 | `ἐνδυσάμενοι τὸν νέον … κατʼ εἰκόνα τοῦ κτίσαντος αὐτόν` | Omul nou se înnoiește spre cunoaștere, după chipul Celui care l-a creat; pronumele se referă la omul nou. |
| COL.3.11 | `τὰ πάντα καὶ ἐν πᾶσιν Χριστός` | Lista etnică și socială este păstrată fără a transforma categoriile în afirmații moderne; concluzia este „Hristos este totul și în toți”. |
| COL.3.12 | `σπλάγχνα οἰκτιρμοῦ … μακροθυμίαν` | Lista virtuților este redată prin îndurare adâncă, bunătate, smerenie, blândețe și răbdare îndelungă. |
| COL.3.13 | `ὁ κύριος ἐχαρίσατο ὑμῖν` | SBL spune „Domnul v-a iertat”; nu este introdusă lectura TR „Hristos v-a iertat”. Îngăduința și iertarea reciprocă sunt păstrate. |
| COL.3.14 | `τὴν ἀγάπην, ὅ ἐστιν σύνδεσμος τῆς τελειότητος` | Dragostea este îmbrăcată peste celelalte virtuți ca legătură a desăvârșirii; pronumele relativ SBL nu schimbă sensul în română. |
| COL.3.15 | `ἡ εἰρήνη τοῦ Χριστοῦ` | Este „pacea lui Hristos”, nu lectura TR „pacea lui Dumnezeu”; ea stăpânește în inimi și se leagă de chemarea într-un singur trup. |
| COL.3.16 | `τῷ θεῷ … ἐν ταῖς καρδίαις ὑμῶν` | Cântarea este adresată lui Dumnezeu și are loc în inimile voastre. TR are „Domnului”, singularul „inima” și conjuncții suplimentare în listă; acestea nu sunt importate. |
| COL.3.17 | `τῷ θεῷ πατρὶ διʼ αὐτοῦ` | Orice cuvânt sau faptă se face în numele Domnului Isus, cu mulțumire lui Dumnezeu Tatăl prin El. Nu este adăugată conjuncția TR dintre „Dumnezeu” și „Tatăl”. |
| COL.3.18 | `ὑποτάσσεσθε τοῖς ἀνδράσιν` | Imperativul către soții este păstrat fără adjectivul `ἰδίοις` („proprii”) adăugat de TR. |
| COL.3.19 | `μὴ πικραίνεσθε πρὸς αὐτάς` | Soții sunt chemați să-și iubească soțiile și să nu se poarte cu asprime față de ele. |
| COL.3.20 | `ὑπακούετε τοῖς γονεῦσιν κατὰ πάντα` | Imperativul copiilor rămâne „ascultați de părinți în toate”; finalul afirmă că aceasta este plăcută Domnului. |
| COL.3.21 | `μὴ ἐρεθίζετε … ἵνα μὴ ἀθυμῶσιν` | Tații nu trebuie să-i provoace pe copii, pentru ca ei să nu se descurajeze. |
| COL.3.22 | `φοβούμενοι τὸν κύριον` | SBL spune „temându-vă de Domnul”, nu lectura TR „de Dumnezeu”. Formula despre slujirea de ochii lor este redată idiomatic ca slujire făcută numai când stăpânii privesc. |
| COL.3.23 | `ὃ ἐὰν ποιῆτε … ἐκ ψυχῆς ἐργάζεσθε` | Versetul începe „Orice faceți”, fără amplificarea TR „și tot”; lucrarea se face din suflet, ca pentru Domnul, nu pentru oameni. |
| COL.3.24 | `ἀπολήμψεσθε τὴν ἀνταπόδοσιν … τῷ κυρίῳ Χριστῷ δουλεύετε` | Este păstrată răsplata moștenirii de la Domnul și afirmația directă „Slujiți Domnului Hristos”; nu este introdus `γάρ` („căci”) din TR. |
| COL.3.25 | `ὁ γὰρ ἀδικῶν … οὐκ ἔστιν προσωπολημψία` | Cel care face nedreptate își primește înapoi nedreptatea, iar părtinirea este exclusă. |
