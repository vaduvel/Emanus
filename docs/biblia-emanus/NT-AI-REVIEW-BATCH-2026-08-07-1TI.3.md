## Decizii pe verset

| 1TI.3.1 | `Πιστὸς ὁ λόγος … ἐπισκοπῆς ὀρέγεται … καλοῦ ἔργου` | `ἐπισκοπή` este redat „slujirea de supraveghetor”, iar persoana din versetul următor „supraveghetor”; nu este impusă o structură eclezială modernă. |
| 1TI.3.2 | `ἀνεπίλημπτον … μιᾶς γυναικὸς ἄνδρα … νηφάλιον, σώφρονα, κόσμιον … διδακτικόν` | Sunt păstrate cerințele distincte: ireproșabil, soț al unei singure soții, treaz la minte, cumpătat, cuviincios, ospitalier și capabil să învețe. |
| 1TI.3.3 | `μὴ πλήκτην … ἀφιλάργυρον` | SBLGNT nu are `μὴ αἰσχροκερδῆ` din TR după „violent”; nu este introdus „câștig rușinos” aici, iar `ἀφιλάργυρον` rămâne „fără iubire de bani”. |
| 1TI.3.4 | `τοῦ ἰδίου οἴκου καλῶς προϊστάμενον … ἐν ὑποταγῇ μετὰ πάσης σεμνότητος` | Conducerea propriei case și copiii în supunere sunt păstrate, iar `σεμνότης` este redat „demnitate”. |
| 1TI.3.5 | `πῶς ἐκκλησίας θεοῦ ἐπιμελήσεται` | Întrebarea rămâne despre îngrijirea „adunării lui Dumnezeu”; nu este păstrat calc-ul deteriorat al versetului anterior. |
| 1TI.3.6 | `μὴ νεόφυτον … εἰς κρίμα τοῦ διαβόλου` | „Nou-convertit” redă persoana recent venită la credință. „Osânda diavolului” păstrează genitivul concis, fără a decide în corpul textului dacă osânda este a diavolului sau asupra lui. |
| 1TI.3.7 | `μαρτυρίαν καλὴν … ἀπὸ τῶν ἔξωθεν … παγίδα τοῦ διαβόλου` | Este cerută o bună mărturie din partea celor de afară, pentru a evita ocara și capcana diavolului; pronumele suplimentar al TR nu modifică româna. |
| 1TI.3.8 | `Διακόνους … σεμνούς, μὴ διλόγους … μὴ αἰσχροκερδεῖς` | Grupul este numit „Diaconii”; sunt păstrate demnitatea, lipsa duplicității, relația cu vinul și refuzul câștigului rușinos. |
| 1TI.3.9 | `τὸ μυστήριον τῆς πίστεως ἐν καθαρᾷ συνειδήσει` | „Taina credinței” este ținută într-o conștiință curată; nu rămâne formula englezizantă din textul precedent. |
| 1TI.3.10 | `δοκιμαζέσθωσαν πρῶτον … διακονείτωσαν ἀνέγκλητοι ὄντες` | Ei trebuie mai întâi puși la încercare și apoi să slujească fiind fără reproș; fragmentul corupt „pu la încercare” este eliminat. |
| 1TI.3.11 | `γυναῖκας ὡσαύτως … πιστὰς ἐν πᾶσιν` | Este păstrat „Femeile”, nu „soțiile lor”: greaca nu dă un posesiv ori un rol explicit. Ele sunt descrise drept demne, necalomniatoare, cumpătate și de încredere în toate. |
| 1TI.3.12 | `διάκονοι … μιᾶς γυναικὸς ἄνδρες … τῶν ἰδίων οἴκων` | Diaconii sunt redați ca soți ai unei singure soții, care își conduc bine copiii și casele; textul nu dezvoltă condiția într-o regulă nespusă. |
| 1TI.3.13 | `βαθμὸν … καλὸν … πολλὴν παρρησίαν` | `βαθμός` devine „o poziție bună”, fără a defini un rang bisericesc; se păstrează și îndrăzneala mare în credința în Hristos Isus. |
| 1TI.3.14 | `ἐν τάχει` | „curând” urmează SBLGNT; TR are comparativul `τάχιον`, care nu este introdus ca „mai degrabă”. |
| 1TI.3.15 | `ἐν οἴκῳ θεοῦ … ἐκκλησία θεοῦ ζῶντος, στῦλος καὶ ἑδραίωμα` | Persoana rămâne singulară („să știi”, „să te porți”); `ἐκκλησία` este „adunarea”, iar `ἑδραίωμα` este „sprijin”, nu „pământul” din textul corupt. |
| 1TI.3.16 | `Ὃς ἐφανερώθη … ἐν πνεύματι` | SBLGNT citește pronumele relativ „Cel care”, nu `Θεός` din TR. „În duh” lasă nerezolvată în corpul versetului capitalizarea și referentul lui `πνεύματι`; cele șase propoziții ale imnului sunt păstrate integral. |
